01

Sequence before sophistication

90-Day Adoption Playbook

Four operating phases, each with one job. Select a phase to see its actions, proof points, and failure mode.

Objective

Build the conditions for a credible launch.

Pick people by task fit, establish the measurement denominator, capture before-metrics, and answer governance questions before they arrive.

  1. 01
    Baseline the work

    Survey recurring tasks and capture 3–5 stopwatch examples.

  2. 02
    Select for task fit

    Prioritize document, email, meeting, and reconciliation-heavy roles.

  3. 03
    Lock definitions

    Write down the denominator, exclusions, activity window, and source.

  4. 04
    Clear governance

    Document permissions, logging, retention, and acceptable use.

Exit signalA named pilot cohort, a written measurement contract, and no unanswered first-week governance question.
Objective

Create useful first wins and publish the truth early.

Train by department, make the first attempt succeed, and report the initial numbers even when they are unimpressive.

  1. W1
    Launch by department

    Send one clear announcement and schedule focused 30-minute sessions.

  2. W2
    Train real tasks

    Each participant leaves with one successful result on their own work.

  3. W3
    Find peer proof

    Identify champions from behavior and participation—not enthusiasm alone.

  4. W4
    Publish the library

    Release department prompts and start the first dormant-user check-in.

Exit signalA repeatable weekly report, visible peer examples, and an honest baseline everyone recognizes.
Objective

Convert early experiments into repeated behavior.

Move from generic training to task-specific support, deepen the prompt library, and act on dormant licenses without drama.

  1. 05
    Run office hours

    Specific problems now outperform another broad curriculum.

  2. 06
    Create a challenge

    Use a low-stakes, two-week campaign to activate the passive middle.

  3. 07
    Build departmental depth

    Turn successful prompts into named, reusable workflows.

  4. 08
    Reallocate deliberately

    Check in at two dormant weeks; reclaim only after a fair support cycle.

Exit signalUsage is concentrated around named weekly tasks—not novelty—and dormant licenses have an owner action.
Objective

Turn the rollout into an operating capability.

Publish the 90-day impact, assign departmental ownership, and graduate repeated prompts into templates, flows, or agents.

  1. 09
    Review what stuck

    Name the workflows that survived and the ones that did not.

  2. 10
    Automate repetition

    Prompts used every week should become more durable systems.

  3. 11
    Distribute ownership

    Give each department a named prompt-library maintainer.

  4. 12
    Set the cadence

    Weekly report, monthly spotlight, quarterly impact review.

Exit signalThe program has owners, operating rhythms, and an automation backlog that no longer depends on launch energy.
