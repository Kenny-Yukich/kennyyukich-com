01

Sequence before sophistication

The four-phase operating system

Each phase includes actions, an exit signal, and the failure mode I would watch. Select a phase to inspect its operating details.

Objective

Make the launch measurable before it is visible.

Allocate scarce seats by task fit, establish the denominator, capture before-metrics, and settle permissions and acceptable use.

  1. 01
    Map recurring work

    Find tasks with enough frequency and friction to justify a license.

  2. 02
    Write the contract

    Name the reporting source, 28-day window, active definition, denominator, and exclusions.

  3. 03
    Clear governance

    Explain permissions, logging, retention, acceptable use, and escalation in plain language.

Exit signalA named cohort, a written measurement contract, and no unanswered first-week governance question.
Failure modeAssigning every seat by seniority produces a cohort with weak task fit and no honest baseline.
Objective

Make the first useful result happen on real work.

Launch by department, coach the first attempt, and publish the baseline even when it is unimpressive.

  1. W1
    Start with the job

    Use the participant's document, meeting, email, or operational decision.

  2. W2
    Run the minimum spine

    Deliver the first focused 30-minute session and schedule the next two.

  3. W3
    Publish peer proof

    Show one specific result, who it helped, and how the next person can repeat it.

Exit signalEvery participant has one usable result and the program has its first honest weekly report.
Failure modeA polished feature tour creates familiarity without changing a single weekly behavior.
Objective

Convert early wins into peer-supported habits.

Deepen examples by department, support the passive middle, and treat dormant seats as a coaching signal before a reclaim signal.

  1. 05
    Run office hours

    Specific stuck points now outperform another broad class.

  2. 06
    Seed the community

    Use prompt-of-the-week, champion spotlights, and a two-week challenge to convert lurkers.

  3. 07
    Support before reclaim

    Check in, coach once, name the task gap, then reallocate deliberately.

Exit signalUsage is concentrated around named weekly tasks, and champions are creating peer pull.
Failure modeChoosing champions by enthusiasm alone creates visible advocates who do not change peer behavior.
Objective

Graduate useful behavior into business capability.

Review what survived, assign ownership, and promote repeated prompts into templates, flows, agents, or applications.

  1. 09
    Review what stuck

    Name the workflows that survived weekly use and retire the ones that did not.

  2. 10
    Apply the graduation gate

    Check repetition, shared value, stable data, ownership, and acceptable error cost.

  3. 11
    Set the cadence

    Weekly signal report, monthly peer spotlight, quarterly capability review.

Exit signalThe program has owners, operating rhythms, and an evidence-backed automation backlog.
Failure modeAutomating novelty creates brittle systems with no owner, no repeat use, and no credible value case.
02

Measure behavior, not assignment

The measurement contract

The number only means something when the source, window, active definition, denominator, and exclusions remain stable.

Published definition / Rev 03

Use the same rules every week

Source
Viva Insights Copilot reporting.
Window
Rolling 28-day activity window.
Active
At least one recorded Copilot action during the window.
Denominator
The named licensed cohort that has entered onboarding.
Exclusions
Assigned-but-not-onboarded seats are tracked separately instead of silently changing the rate.
Publication
Organization-level totals only; no user names, prompts, or individual activity.

03

Champions + training

Turn training into peer proof

The loop is training, champions, peer success stories, reusable prompts, and then measurement.

01

Identify from behavior

Look for repeat use, useful questions, and a willingness to help peers, not launch-day excitement.

02

Give a small job

Own one department example, office-hour slot, or prompt-library improvement.

03

Publish peer proof

Show the task, result, guardrail, and how someone else can repeat it.

04

Measure community health

Watch repeat contributors, unanswered questions, and department coverage.

Prompt of the week / Meetings

Turn this week's meetings into an action register

Review my meetings from this week. Create a table of action items with columns for owner, due date, source meeting, and status. Put anything assigned to me first. Flag any item with no owner or due date. Do not invent missing details.
