The prompt is not the control system

Good task design helps, but permissions, approved sources, human review, and accountable decisions still define safe use.

01 / Grounding

Name the source boundary

Point the task at approved project files, released drawings, manuals, policies, exports, or records. Ask the model to show conflicts instead of resolving them silently.

Control: traceable sources
02 / Review

Keep approval human

Use Copilot to retrieve, compare, structure, and draft. Leave engineering approval, safety judgment, purchasing authority, and people decisions with the responsible role.

Control: named approver

Validate the value claim

Estimated time savings are hypotheses. Compare task time, quality, rework, and adoption before presenting a business case.
